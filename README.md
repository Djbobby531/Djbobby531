## 🚀 Featured Projects

### ♟️ [ChessIQ](https://github.com/Djbobby531/ChessIQ) — AI Chess Coaching App
> *Full-stack FastAPI app that coaches you like a Grandmaster would*

A production-grade chess analysis platform that accepts SAN/PGN moves and delivers deep, personalized coaching feedback — built end-to-end from board state parsing to LLM-generated explanations.

- 🔍 Scores games across three phases: **Opening · Middlegame · Endgame** (0–100 scale, Beginner → Master tiers)
- 📖 Matches moves against **500+ named openings** (ECO dataset, first 30 plies)
- ⚡ Stockfish depth-20 analysis with heuristic fallback — works with or without the engine
- 🤖 LangChain + OpenAI-compatible LLM explanations for critical positions
- 🎮 Play-vs-computer mode with difficulty levels and built-in game coach
- 💾 PostgreSQL persistence via SQLAlchemy (SQLite fallback for local dev)

**Tech:** `Python 3.11` · `FastAPI` · `LangChain` · `Stockfish` · `PostgreSQL` · `SQLAlchemy` · `python-chess`
